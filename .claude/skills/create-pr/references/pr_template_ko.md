# PR 본문 템플릿 (한국어 / 기본)

이 저장소가 한국어 기반이거나 특별한 신호가 없을 때 **기본으로 사용**하는 템플릿이다. `<...>` 부분을 실제 diff·커밋 히스토리에 근거해 채우고, 확인되지 않은 내용은 지어내지 않는다.

```markdown
## Summary
- <핵심 변경 1: 무엇을 왜 바꿨는지>
- <핵심 변경 2 (필요 시)>
- <핵심 변경 3 (필요 시)>

## Test plan
- [ ] <실행했거나 실행해야 할 테스트/빌드/린트>
- [ ] <수동으로 확인한 동작, 또는 확인이 필요한 시나리오>
```

## 작성 규칙

- `Summary`는 diff에서 실제로 확인된 변경만 불릿으로 나열한다. 성능 개선 수치, 효과 등은 측정 근거가 없으면 쓰지 않는다.
- `Test plan`은 실제로 실행한 검증이면 체크된 상태(`- [x]`)로, 실행하지 않았거나 사용자가 직접 확인해야 하면 미체크(`- [ ]`) 상태로 남긴다. 검증 수단이 전혀 없으면 "실행 여부 미확인"이라고 솔직히 적는다.
- 섹션 제목(`## Summary`, `## Test plan`)은 그대로 유지한다. 필요하면 그 아래에 `## 관련 이슈` 등 추가 섹션을 덧붙일 수 있다.
- 본문 마지막에는 대화의 system-reminder에 지정된 attribution 라인을 그대로 추가한다(이 템플릿에는 포함하지 않는다 — 스킬 실행 시점에 덧붙인다).
